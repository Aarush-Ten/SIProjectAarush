# Phase 2 local demo

1. Start the backend on port 8000 and frontend on port 3000 using the README. Open the landing page and select **Find my pathway**.
2. Use the clearly labeled illustrative profile: diploma student, Python level 2, HTML level 2, SQL level 1, cybersecurity interest. Leave networking and Linux unreported, which means level 0.
3. Continue through constraints: 6 hours per week, INR 0 learning budget, laptop access, English. Choose a goal and review the guest data notice.
4. Submit. Show exactly three career matches and their API-provided component scores. Explain that skill coverage concerns self-reported essential skills, while fit combines coverage, interests, and feasibility.
5. Inspect essential and optional gaps. For SOC Analyst, networking and Linux start at 0, with the missing levels determined by the catalog. The highest-ranked role is determined by the formula; it is not forced to match an interest.
6. Open the calculation disclosure and explain the 60/25/15 weights and feasibility rules. These are reviewable assumptions, not a placement prediction.
7. Keep the original 6-hour laptop profile for the first plan. Note that changing constraints later will replace a plan based on the older profile.
8. Open the SOC career detail page, review the essential/optional requirements and calculation, then select **Create my roadmap**. Show weekly hours, checked reference links, activities, verification methods, and the manual milestone. Explain that durations are illustrative and resource fees exclude equipment and supervision.
9. Mark the first available task done. Show task/hour progress, refresh, and confirm the same profile, plan, and completion are restored. Reopen the task to show recalculated progress and dependent-task reopening.
10. Compare the 6-hour laptop plan with a new 4-hour smartphone-only plan. Show the changed weekly packing and theory alternatives. State clearly that computer practicals or supervised equipment access remain necessary.
11. Use **Clear saved data** to remove the browser-local journey. Visit `/dashboard` and `/roadmap` to show their empty states. On shared devices, explain that data is local and has no account protection.

End at the learning plan and its local progress. Backend-graded assessments, AI adapters, and translations belong to Phase 3 and are not implemented. No pilot results, placement rates, salary promises, or live job demand claims are available. A fast automated journey does not establish measured newcomer usability; the three-minute goal still needs human validation.
