Reproduction: build the frontend, set `PLAYWRIGHT_CHANNEL=msedge` on this Windows host, then run `npm --prefix frontend run record:walkthrough`. Playwright owns/stops the two test servers and saves `docs/media/pathforge-walkthrough.webm`. Install its FFmpeg helper beforehand as described in the release checklist. Avoid running other services on ports3000/8000 during recording.

For a live pitch, open the production API health page ahead of the session to allow a free backend to wake. Use the actual verified public URL only after deployment; the local recording must stay labeled local if deployment is still pending.
